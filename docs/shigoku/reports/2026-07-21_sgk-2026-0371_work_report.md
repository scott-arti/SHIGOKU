# 作業報告書：AuthProbe relative redirect handling follow-up

## 1. 実装概要

`AuthProbe` が `Location: login.php` のような相対リダイレクトを再訪できず、`ClientError` を `TARGET_CONNECTION_FAILURE` へ誤変換していた。redirect target の解決を `urljoin()` に統一し、ログインページ判定へ進めるよう修正した。

## 2. 変更内容

### 2.1 Redirect target 解決の修正
- **ファイル**: `src/core/preflight/auth_probe.py`
- **変更**:
  - `urllib.parse.urljoin` を追加
  - manual redirect follow で `Location` を `urljoin(str(response.url), location)` で解決
- **狙い**:
  - absolute / root-relative / relative の 3 系統を同じ経路で処理する
  - `login.php` のような DVWA 風リダイレクトを `ClientError` にしない

### 2.2 回帰確認
- **ファイル**: `tests/unit/preflight/test_auth_probe.py`
- **確認内容**:
  - 既存の `test_relative_redirect_login_page_is_classified_as_login_page` を red/green の回帰テストとして利用
  - 修正前は `CONNECTION_FAILURE`、修正後は `LOGIN_PAGE` へ戻ることを確認
