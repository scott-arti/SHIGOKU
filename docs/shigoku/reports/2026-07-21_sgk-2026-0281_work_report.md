# 作業完了報告書：SGK-2026-0281 Recon運用再設計

## 達成内容
Reconのresume、import-recon再利用、recipe選択、PhaseGateの硬化を実施した。
全8ステップのうち、主要なコード変更（Steps 2-7）を完了。Step 1（ギャップ分析）とStep 8（検証）を含め、計画書の実装スコープを完了。

## 変更概要

### 1. MC resume 共有検証経路への硬化 (`src/core/engine/master_conductor.py:9386-9407`)
- `ReconState.load()` の直接呼び出しを廃止し、`ReconState.validate_for_resume()` 共有バリデータ経由に変更
- `resume_verdict` の `reason_code`, `next_step`, `can_resume` をログに記録
- fail-closed: バリデータが拒否した場合はresumeせずフレッシュ実行

### 2. ATTACK 解放条件の actionable 化 (`master_conductor.py:9470-9505`)
- `count > 0` による単純判定を廃止
- `non_actionable_categories`（`uncategorized`, `external_link`, `invalid_candidate`）を除外
- `_signal_bundle` のシグナル有無も actionable 判定に含める
- 解放時・非解放時のログに actionable カテゴリ内訳を出力

### 3. import-recon provenance の硬化
- `recon_importer.py`: 各 artifact に `artifact_hash`（SHA-256[:16]）を付与
- `recon_importer.py`: `fingerprint_match` 状態を provenance に記録
- `master_conductor.py`: `_merge_imported_recon_results()` にて全 accepted artifact のハッシュ・カウント・フィンガープリントを `_import_provenance` へ集約

### 4. レシピ決定マトリクスの可観測性強化 (`master_conductor.py`)
- `decision_stats` 辞書で各分岐（`recipe_executed`, `manual_review_required`, `low_confidence`, `unsupported_action`, `suppression_active`, `no_recipe_match`, `swarm_fallback`, `gate_rejected`）を計数
- シグナルルーティング後に決定マトリクスの内訳をログ出力

### 5. PhaseGate gate_rejected 計数 (`master_conductor.py`)
- フォールバックパスの `can_create_attack_task` 拒否時に `decision_stats["gate_rejected"]` をインクリメント
