# SGK-2026-0350: 作業完了報告書

## 1. 達成目標

1. security-critical role（`final_judgement`）のプレースホルダー実装を完全再実装する
2. 極端に短い role プロンプト（`specialist_light`, `vuln_validator`, `chain_proposer`, `attack_suggester`）に具体的指示と出力スキーマを付与する

- **Step 1-1 `final_judgement.md` 完全再実装**: 2行プレースホルダー → 40行。True/False Positive 判定基準 + 厳密 JSON スキーマ（`valid`/`confidence`/`severity`/`reasoning`/`evidence`/`false_positive_indicators`/`remediation`）+ confidence < 0.7 なら valid:false ルール。

- **Step 1-4 `vuln_validator.md` 拡充**: 4行 → 45行。検証プロセス4ステップ + 判定ルール + False Positive 典型例 + JSON スキーマ。
