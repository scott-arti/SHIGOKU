# 作業報告書: SGK-2026-0361 Runtime Artifact Path Root Cause Fix

## 完了ステータス
SHIGOKU実行後にartifact一覧が`/app/workspace/...`として表示される根因を調査し、内部保存先の設定正本とユーザー向け表示パスを分離する修正を完了した。

## 原因
`src/main.py`のauto report bundle summaryは、生成されたartifact `Path` をそのまま表示していた。

artifact生成元の`ProjectManager`は、デフォルト`workspace/projects`をコード配置ルートから解決していたため、Docker/DevContainerでコードが`/app`に配置されると内部保存先も`/app/workspace/projects`になっていた。これは表示だけの問題ではなく、実行環境内の保存基準が`/app`へ暗黙に寄る構造だった。

| `docker-compose.phase-d.yml` | app/testサービスに`/workspace`マウントと同環境変数を追加した。 |
