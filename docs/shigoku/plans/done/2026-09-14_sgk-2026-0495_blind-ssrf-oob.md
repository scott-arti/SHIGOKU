# SGK-2026-0495 計画 — Blind(OOB) SSRF を実対象で本物確定（◎・OOB 基盤の横展開）

## 背景・方針

SGK-2026-0494 で整備した OOB 基盤（`OOBProvider`＋`LocalOOBProvider`＋汎用マーカー
`oob_interaction_received`＋`_check_oob_replay`）を**横展開**し、blind SSRF を ◎ 化。SSRF は
「サーバがリクエスト中の URL を fetch するが結果を返さない」ため、我々の OOB 受信器を fetch 先に
指定し token 到達で確定する。宛先を変えるだけ＝新エンジンは Finding を作るだけ。

## 事実（偵察で実測）

- **OWASP SKF ラボ `blabla1337/owasp-skf-lab:ssrf`**（Flask）を `--network host` で起動。
  `POST /check_existence` form `url` を `validators.url` 検証後 `requests.head(url, timeout=2)` で
  **サーバ側 fetch**（結果は "Webpage found!/reacheable" 等のみで内容非返却＝実質ブラインド）。
- 実測で URL パラメータに OOB コールバックを入れると標的サーバが `HEAD /callback/<token>` で
  我々の受信器へ到達＝blind SSRF OOB 成立（`--network host` でラボ→受信器到達）。

## 対象（完了契約）

SKF ssrf ラボの blind SSRF を実対象で **機械フロア＋実再現＋実 poc_judge の完全3ゲート**で ◎。
確定は「一意 token 付き callback URL を URL パラメータに入れて送り、標的サーバが我々の受信器へ
その token で到達」で行う（汎用 OOB マーカー流用）。非破壊。

## 実装方針（新設1＋承認済み凍結1・最小）

1. **新エンジン `injection/smart_blind_ssrf.py`（非凍結・新規）**: `SmartBlindSSRFHunter`。OOB provider
   から一意コールバックを発行し、候補 URL パラメータ（url/uri/target/webhook/… 汎用）× モード
   （form/query/json）に callback を入れて送信→poll で token 到達を確認→確定。`self._client`／`self._oob`
   seam。`oob_evidence`（token/callback/payload＝token を含む送出値）＋`oob_replay`（mode/param/
   payload_template="{OOB}"）＋生 OOB inbound リクエストを載せた poc。製品固有ハードコードなし。
2. **確定バー `payout_grade.py`：改変なし**（汎用 OOB マーカー `oob_interaction_received` は vuln_type
   横断で ssrf も既存カテゴリのため発火経路に乗る）。
3. **再現チェッカー `sealed_reproduction_checker.py`（凍結・承認）**: `_check_oob_replay` に **query（GET）と
   json（POST）モードを追加**（従来 form/raw に加え）。SSRF の URL パラメータ再現に対応。SKF は form
   なので本追加なしでも通るが、実標的（GET ?url= / JSON {url:}）への汎用性のため拡張。

## 完了条件

1. 実 SKF ssrf ラボで実 `SmartBlindSSRFHunter.execute` が blind SSRF を OOB で自走検出→
   payout_grade=True/oob_interaction_received。
2. 実 `SealedReproductionChecker`（oob_provider 注入）が新 token で再送し受信器再観測→matched→CONFIRMED。
3. 本物の poc_judge（実 LLM）で承認（生の OOB inbound リクエスト＋token 相関を提示）。
4. 製品非依存 fixture の新規テスト緑（engine OOB 確定・非到達で不確定・query/json replay 記述子・poc 形式／
   sealed OOB query モード matched）。
5. 凍結3 exit 0（payout_grade は本タスク不変）。製品トークン 0・秘密値非露出・回帰ゼロ。
